# HDA 查询工具使用说明

**版本：v1.1**

HDA 查询工具用于从 OPC UA Historical Access 服务读取历史数据、导出 Parquet 文件，并对已导出的结果进行趋势分析和明细查看。

## 1. 连接配置

窗口顶部的连接配置在所有页面中始终可见。

| 项目 | 说明 |
| --- | --- |
| URL | OPC UA 服务地址，例如 `opc.tcp://127.0.0.1:48630/hda-mocker/` |
| NS | 位号所属的 Namespace Index |
| 连接 | 检查服务器是否可访问；查询时仍会为本次任务建立独立连接 |

上次使用的配置会自动保存，并在下次启动时恢复。

## 2. 查询历史数据

### 查询条件

1. 填写截止时间，格式为 `yyyy-MM-ddTHH:mm:ss`。
2. 填写查询时长并选择秒、分、时或天。
3. 设置单页上限，默认 `5000`。服务端可以按自身限制返回更少的数据。
4. 确认 Parquet 输出路径。默认文件保存在程序旁的 `data` 目录。

### 输入位号

支持三种方式：

- **直接输入**：使用逗号、中文逗号、分号、空格或换行分隔多个位号。
- **表达式**：例如 `M{index:4d}.VALUE[0,9999]`，表示 `M0000.VALUE` 到 `M9999.VALUE`。
- **CSV 导入**：CSV 第一列为 `node`，可先下载模板再填写。

### 执行与结果

点击“查询”后，页面显示位号进度、记录数、耗时和吞吐率。查询过程中可以取消。完成后会显示 Good、Bad、Uncertain 和无值记录数量，并生成 Parquet 文件。

## 3. 异常值

“异常值”会扫描整份 Parquet，不受“数据详情”中的位号选择影响。查询完成后可以直接点击“查看异常值”，导航栏徽标会持续显示异常记录数量。

- **Bad**：OPC UA 状态码为 Bad 的记录。
- **Uncertain**：OPC UA 状态码为 Uncertain 的记录。
- **Good 空值**：状态为 Good，但 Variant 没有实际值的记录。
- 连续出现的同类异常会合并为一个时间段。
- 支持按异常类型筛选、按位号搜索和分页查看。

## 4. 数据详情

点击“选择”默认打开程序旁的 `data` 目录，也可以直接输入 Parquet 路径后按回车。

### 选择位号

- 左侧列表支持搜索、单独勾选、全选和取消。
- 位号数量很大时列表采用虚拟滚动，不会一次渲染所有项目。
- 摘要中的记录数和质量统计只计算当前选中的位号。

### 曲线视图

- 曲线由后端按 Min/Max 时间桶降采样，尽量保留尖峰。
- 在图中按住鼠标并横向拖拽，可以框选时间范围。
- 框选后点击“显示全部”恢复完整时间范围。
- 同时选择大量位号时，曲线显示前 12 个；统计和表格仍包含全部选中位号。

### 表格视图

- 表格显示时间、位号、值和质量。
- 表格区域拥有独立滚动条，表头保持可见。
- 使用下方的上一页、下一页或页码输入框进行翻页。
- Bad 和 Uncertain 记录使用不同的背景色标识。

## 5. 文件与数据

- Parquet 使用长表结构，每行包含时间、位号、值、质量和是否有值。
- 时间在文件中以 UTC 纳秒保存，界面按本机时区显示。
- 查询先写入临时文件，只有完整成功后才生成目标 Parquet；取消或失败不会留下不完整结果。
- 配置文件位于当前 Windows 用户配置目录下的 `hda_client/config.json`。

## 6. 常见问题

### 为什么一次查询会收到多个数据页？

服务端可以限制单页长度。客户端会自动携带 continuation point 串行读取同一位号的后续页面，直到服务端返回空 continuation point。

### 为什么曲线点数少于表格记录数？

曲线为了流畅显示进行了降采样；表格和 Parquet 文件仍保留原始记录。

### 为什么选择很多位号后分析需要等待？

统计与表格需要扫描选中位号的数据。建议先通过搜索缩小位号范围，再进行趋势比较。
