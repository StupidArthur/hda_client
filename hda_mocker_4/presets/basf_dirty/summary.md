# BASF 稀疏原始观测

统计基线：2026-10-18；适用于 hda_mocker_4 v1.5.0。本文描述本目录的输入数据，不是运行状态、实时追加历史或性能实测报告。配置摘录为编写时快照；连接地址和播放配置以同目录 `config.yaml` 的当前内容为唯一来源。

## 数据概览

本目录保留 时间戳_整理后_25位号_原始观测.csv。源时间按 Asia/Shanghai 解释，转换为UTC；Parquet保留原始毫秒时间精度，以UTC微秒类型存储。

25个位号异步观测合并成宽表，时间不等间隔、列高度稀疏。表格行数不等于单个位号的观测数。每列都至少有一个有效值，空格表示该时刻没有该位号观测，不是Bad。

| HDA 结束时间（UTC） | `2026-10-16T05:57:23.634000Z` |
| HDA Good / Uncertain / Bad | 243,248 / 0 / 0 |

以上实际点数按“有限值或明确Bad”统计；Good/Uncertain/Bad按完整UA状态码最高两位分组，不能仅用 status==0 判断Good。数值0与质量码0含义不同。

## DA 轮播与实时 HDA

- 文件：`da/basf_dirty.parquet`，103,547行，25个位号，一轮含243,248个实际观测。
- 轮播模式：源时间轴，按原始相对时间差循环播放。
- `period_ms`：100（配置保留该项；实际按Timestamp时间差，每100ms检查）。
- 一轮计划周期：72 小时 12 分 54.156 秒，为源首末跨度加100ms；末行到下一轮首行间隔100ms。这是计划时间，不是对实际调度延迟的保证。
- 一轮 DA Good / Uncertain / Bad：243,248 / 0 / 0。

零和负数是有效值，不做清洗。AI390101C05的10个值全为0；PV391303B有7个负值、PV391303C有2个负值；FIC391205在2026-10-15T07:04:00.151Z为5500。原CSV没有质量列，有效观测默认Good，不代表已验证现场原始质量。

空格不产生新观测：HDA不写该点，DA保持前一个值和质量；第一轮前面没有值时沿循环顺序向上一轮尾部找最近观测初始化，初始化不写入HDA。重启从首行开始，历史事务成功后才更新DA；100ms检查不等于每个位号100ms必更新，也不保证每条中间订阅通知都送达。

## 质量、空值与数据特征

本数据集是空值规则的例外：2,345,427个对齐空格均为无观测（约90.60%），不能把它们补成Bad、0或HDA保持值。所有有效原始观测使用默认Good。

## 当前配置快照

```yaml
server:
  endpoint: opc.tcp://0.0.0.0:4841
  ns: 3
  namespace: urn:hda:mocker4:basf
  max_page_size: 5000
playback:
  files:
    basf_dirty.parquet:
      period_ms: 100
history:
  retention_days: 0
```

- 当前UA监听：`opc.tcp://0.0.0.0:4841`；Namespace URI：`urn:hda:mocker4:basf`；配置索引：3。
- 节点位于 `Objects/HDA_Mocker`；例如 `ns=3;s=FI391303`。客户端宜通过Namespace URI解析实际索引。
- 历史单页上限：5000；`retention_days: 0`，0表示不自动清理实时历史。
- HTTP诊断：当前config未配置diagnostic.listen，即未启用HTTP诊断；网站应显示未监控，不能假定一个诊断端口。

当前地址仍使用 `0.0.0.0` 监听占位，并非可复制给用户的连接地址。实际部署时由管理员在本 `config.yaml` 中填入属于运行机器、用户可访问的IP；网站只读取它，不再另维护连接地址。各preset现有示例端口存在复用，不能原样全部同时启动，部署时需在各自config中安排不冲突的UA/诊断监听端口。本文不替代或覆盖当前config。

## 使用与下载

可下载本目录的 `hda/*.parquet`、`da/*.parquet`（有则提供）、`config.yaml` 和 `summary.md`。`runtime/`、DuckDB/WAL、日志和原始现场文件不作为门户默认下载内容。网站只展示说明与文件，不在线扫描或改写这些Parquet。

Raw HistoryRead应设置 `ReturnBounds=false`；正常分页时 `ReleaseContinuationPoints=false`。所有时间使用UTC，保留原微秒/毫秒精度。换用迁移后的preset应新建runtime，不能仅替换文件而复用已导入旧质量码的历史库。本文的诊断、周期和数据特征不构成长期运行性能验收结论。
